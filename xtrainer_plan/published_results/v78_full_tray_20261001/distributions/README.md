`Cmax` 是单次完整抓放中，对各关节累加相邻采样的绝对转角，再取六关节最大值；`span` 是全程最大角减最小角，再取六关节最大值。有效限位余量使用 CuRobo 收紧后的 ±3.00 rad 位置区间，取整个单件轨迹中所有关节距上下限的最小值；`rad` 是弧度。每个图格内的数值单位为度。

全部位置沿用保留的 `task_world` 世界坐标系；抓取 z=0.030 m，近臂/远臂基座为 (−0.10/−0.72, 0.15, 0.65) m，固定放置位置为 (−0.02/−0.82, −0.12, 0.10) m。三角形是基座投影，X 是固定 place，+ 是保留的坐标原点。

图的生成过程逐项核对轨迹和报告哈希、窗口独立审查、原始格点坐标及每格恰好一次抓取/放置事件；最终完整报告还要求覆盖全部 400 个不同格点。代理球模型尚未包含持物、已放物料、完整工具外壳及线缆。
