# V52 起：基座 XY × place X 笛卡尔积冒烟（双侧 0.14 rad）

## 任务与不变条件

本轮按用户要求，将上方单臂基座放在 grasp 的原始 LINK0 +Y 一侧，扫描基座 X、Y 与 place X 的完整笛卡尔积。place Y 固定 −0.12m，高度仍 0.10m。先做冒烟，不直接运行20×20全量；不替换默认配置或当前RViz模型/轨迹。

所有坐标均指原始 `task_world/original_LINK_0`。保留向下安装 RPY=(180,0,90)°、基座Z=0.65m、TCP偏移0.19m（相对原始缩短3cm）、单臂无mimic。grasp范围 x=[−0.62,−0.20]、y=[−0.10,0.40]、z=0.03m，中心(−0.41,0.15)。Home的位置(−0.31,0,0.03)、姿态和IK种子保持不变。

六轴从原始URDF上下限各内收 **0.14rad**，替换原来的0.15而不是累加。原始限位±3.14rad，故本轮实际有效限位 **±3.00rad**。`criterion.min_limit_margin_deg=0`，避免重复内收。正常IK、MotionGen及其rollout均应采用此限位，另逐一复核所有保存的轨迹采样。

保留grasp/place耦合的0,−2,…,−30°角度搜索；独立IK预筛关闭；J1–J5单段跨度≤170°，直线段3mm/5°；全24球自碰撞，世界六面墙只约束LINK3/LINK6的12球。未擅自添加J6跨度拒绝条件或grasp物体障碍。LINK3与grasp有限参考平面的关系单独报告。

### 验证与选型办法

每组先规划完整抓放，再生成规划/失败汇总、LINK3间隙诊断、独立新模型FK/自碰撞/墙碰撞/限位复核，以及原始URDF相对余量审计。只有完成且独立验证通过的轨迹才参与推荐排名。检查覆盖保存的全程离散采样，不等于对连续时间扫掠、实机跟踪误差或真实物体/CAD的安全证明。

先按完整成功点数选候选，并展示J6余量/绕转和LINK3放置阶段诊断。在粗网格上较好的几组加密到5×5；粗网格9/9也不能当成整个矩形或20×20全量成功。当前规划采用连续case执行，失败case不更新当前关节状态，Home分支和前一成功轨迹可能影响后续分支。
