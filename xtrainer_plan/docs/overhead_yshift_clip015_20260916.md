# V50 起：双侧 0.15 rad 下的小步 +Y 安装对照

承接[V49 全量检查](overhead_joint_margin_015_20260916.md)。用户观察当前图的原始 Y 负侧较易成功，同意将天上基座沿原始 LINK0 的 +Y 移动一些再试。

## 对照设计

V50 采用同一 **5×5 完整抓放点阵**，并重跑当前位置作为同网格基线：

| 安装位置（原始 LINK0，m） | 相对当前 +Y 平移 |
|---|---:|
| (-0.36, 0.15, 0.65) | 0cm，基线 |
| (-0.36, 0.20, 0.65) | 5cm |
| (-0.36, 0.25, 0.65) | 10cm |
| (-0.36, 0.30, 0.65) | 15cm |

保持安装 RPY=(180,0,90)°、TCP=0.19m、grasp x=[-0.62,-0.20] / y=[-0.10,0.40] / z=0.03、place=(-0.16,-0.23,0.10)、Home=(-0.31,0,0.03)不变。Home 原姿态和 IK 分支种子也保持一致，仍由 IK 求解验收；没有直接指定关节起点。

六个关节都按原始 URDF 双侧各内收 0.15rad，规划范围 ±2.99rad。保留0,-2,…,-30°抓放同角搜索、关闭独立IK预筛、J1–J5单段跨度170°、直线3mm/5°、全部24球自碰撞和LINK3/LINK6世界墙约束。未新增J6跨度拒绝条件或grasp物体障碍。

主配置从保存的 V49 派生；没有改变默认安装、旧结果或当前 RViz 播放。对比结果保存在 [V50目录](../results_overhead/20260916/v50_yshift_clip015_smoke)。

## 坐标与碰撞场景检查

在已有悬挂配置上只平移安装，不能再次套用“原始安装→悬挂”的整套变换。新增 `derive_overhead_experiment.py --mount-position X Y Z`：使用 `new_from_old = inv(M_new) @ M_old` 更新规划目标修正和规划基座下的工作空间，使 `M_new @ C_new = M_old @ C_old`。原始任务目标与六面墙的物理位置不变。

四组生成配置均已逐项核对：只改安装位置及其坐标换算、网格密度和溯源；Home、place、角度/直线/跨度判据和planner均与V49相同。4项新CPU测试验证安装方向、原始任务/非单位修正保留、物理世界墙不动、源配置不变及非法输入拒绝；原有派生脚本6项测试仍通过。

当前相对坐标 `x_new = y_original - y_mount`。安装向原始+Y移动，会使固定grasp和place都向新基座−X移动；这可能让更多抓取点处于当前较有利的一侧，但place也更远，因此不能把V49的成功图直接平移作为新可达区。

## V50 结果

四组实际轨迹冒烟均已完成，全部成功采样通过独立FK、自碰撞、现有世界墙及0.15rad限位审计。各实际结果目录内保存 `analysis_summary.json`、`link3_grasp_clearance.json`、`independent_verification.json`、`joint_limit_clip_audit.json`。没有用端点IK成功代替完整抓放成功。

四组保存样本数分别6574、6212、6163、2714。J6距内收后的有效限位不足1°的成功case分别0、4、0、0；全部六轴仍满足相对原始URDF至少0.15rad（允许1e-6rad数值容差）。图标题的“近有效限位成功”统计所有关节，不等于J6单独统计。

相对基线，三组外移都只新增成功index12；分别丢失3、4、13个原成功点。当前结果不支持“仅沿+Y移动就全面改善”：y=.25改善了本次成功集合的J6余量/跨度，但成功数降低，LINK3放置间隙也没有整体改善。

### 相同case对齐，避免成功集合偏差

y=.20与基线共同成功16点，其中J6最小原始限位余量改善11点、变差5点；LINK3放置阶段最低高度改善1点、变差15点。四档共同成功只有index11、15、17、24，相对基线的J6改善/变差数依次为2/2、3/1、2/2，LINK3为1/3、1/3、2/2。

- index11、原始位置(-0.41,0.025,0.03)：从y=.15移到.20后，J6原始余量15.682°→147.021°，但LINK3放置最低高度从高于grasp平面179.61mm降为低于2.42mm，出现15个平面相交采样。
- index17、原始位置(-0.305,0.15,0.03)：同样移动，LINK3高度207.45mm→219.03mm，而J6原始余量11.204°→8.599°，距内收后的边界只剩约0.00474°。

这些仍是当前规划器选出轨迹的比较，不是单纯几何偏移的单调性证明；抓取角、前一成功case的状态和选中的分支都可能改变。

### y=.30低成功率的原因

Home IK实际成功，关节为[-32.19,102.76,-68.26,-124.50,-90,32.19]°。前11个case的176次尝试中，150次因真实轨迹段跨度超过170°被拒，15次IK_FAIL、11次优化失败；120次发生在g_lift_in、54次p_lift_in、2次grasp。

失败case不会更新连续规划的当前关节状态，因此在index11首次成功前一直从同一Home构型起步。证据说明本次Home/转移分支组合受到了跨度判据限制，不能说这些点物理无解；尚未额外测试替换Home分支。全部18个失败case的末次状态为16个跨度超限、2个IK_FAIL。

### 独立复核与限制

[新模型FK/碰撞/限位复核](../results_overhead/20260916/v51_y020_clip015_full/v51_y020_clip015_full/independent_verification.json)和[实际IK/MotionGen限位审计](../results_overhead/20260916/v51_y020_clip015_full/v51_y020_clip015_full/joint_limit_clip_audit.json)均通过。全部87,754采样自碰撞0、对既有世界墙碰撞0、关节超限0；全关节最小原始URDF余量0.14999999046rad，float32误差在1e-6rad容差内。IK与MotionGen及其rollout仍都使用双侧0.15rad内缩。

规划分段验收记录的J1–J5最大单段跨度169.99914°；最大直线偏移2.17955mm、姿态偏差1.99937°，均符合原判据。夹爪相对信息性soft bounds的越界139采样、最大53.80mm，仍按原配置只报告，不作为世界墙硬碰撞。

[LINK3诊断](../results_overhead/20260916/v51_y020_clip015_full/v51_y020_clip015_full/link3_grasp_clearance.json)：全程153条成功case、21005个采样与grasp有限参考平面相交；放置相关149条、16719个采样。最低球面相对平面−97.043mm在index180的`i180_p_lift_in`，sample39276、t=785.52s。grasp区仍没有真实物体高度障碍模型，故它与原世界墙验证通过并不矛盾；这些结果不是实机安全证明。

## 本轮结论与保留配置

当前固定Home、grasp/place、朝向、角度搜索和规划判据下，测试的三个小步+Y偏移没有找到比原位置全面更好的方案。原位置y=.15仍保留为当前默认安装和RViz播放；新配置及轨迹仅作为独立实验保存。y=.25的冒烟J6指标值得注意，但未做全量，不能据此承诺它的400点成功率或物体避让。

本轮没有另换Home IK分支、扩大角度范围、移动place或改变J6跨度/物体障碍约束。安装效果和所选连续轨迹分支相关，因此此结果也不证明所有+Y位置或其它规划分支都不能改善。
